# math-proofs

Lean 4 / Mathlib formalisation of the BBP digit-extraction formula for π and explicit
guard depths for every hex digit, with the accompanying paper, by Brian Bernard Taylor.

The Lean sources and the paper arrive on branch `snapshot/v1`.

Toolchain: `leanprover/lean4:v4.29.0-rc8`; Mathlib pinned to
`816ff4582a01b10567d1d4ecb10be7c4ff92aab4` in `lakefile.lean`.

(see `LICENSE`).
